Dual-Server Public-Key Encryption with Keyword Search

End-to-end secure cloud storage demo where files are encrypted with AES, keywords are transformed using DS-PEKS, and search runs through Front Server + Back Server simulation without exposing plaintext keywords.

Data Owner Experience

Upload files, inspect secure processing traces, and manage encrypted cloud documents.
